# CARDAPIO — Estação Burguer 🍔

Um **cardápio digital** desenvolvido em **JavaScript, HTML e Tailwind CSS**, criado originalmente para o restaurante *Estação Burguer*.  

O sistema permite que o cliente monte seu pedido de forma prática e rápida, adicionando ou removendo itens do carrinho, preenchendo endereço e finalizando o pedido dentro do horário de funcionamento do restaurante.  

Ao concluir, o pedido é automaticamente enviado para o **WhatsApp do estabelecimento**, onde são tratados o pagamento e a entrega.

---

## ✨ Funcionalidades

- 📋 Exibição do cardápio com produtos, preços e imagens  
- ➕ Adição de itens ao carrinho  
- ➖ Remoção de itens do carrinho  
- 💰 Cálculo automático do valor total  
- 🏠 Campo obrigatório de endereço para entrega  
- ⏰ Verificação de horário: pedidos só podem ser enviados quando o restaurante está aberto  
- 📲 Envio do pedido finalizado diretamente para o **WhatsApp do restaurante**  

---

## 🛠️ Tecnologias Utilizadas

- **HTML**  
- **CSS (Tailwind CSS)**  
- **JavaScript**

---

## 🚀 Como funciona o envio pelo WhatsApp

Quando o cliente finaliza o pedido:  
- O sistema gera uma mensagem com os itens escolhidos, quantidades, valor total e endereço informado  
- A mensagem é enviada automaticamente para o WhatsApp do restaurante  
- O estabelecimento recebe a solicitação e trata diretamente o **pagamento e a entrega**  

---

## 📌 Observação

O projeto foi utilizado no restaurante *Estação Burguer* (hoje encerrado), mas pode ser facilmente adaptado para qualquer outro negócio que queira adotar um **cardápio digital integrado ao WhatsApp**.
